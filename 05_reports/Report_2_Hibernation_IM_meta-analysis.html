This R Markdown Notebook contains the initial meta-analysis for the project ‘physiological ’costs’ of hibernation. Specifically, the meta-analysis of hibernation.

Dataset and calculation of effect sizes

The dataset for this meta-analysis has been collected from the literature and curated by Pablo Burraco, Marko Prokic and Tamara Petrovic. It contains data on physiological effects of hibernation in different systems. Here a quick snapshot of the first lines of the dataset:

For this initial meta-analysis, I am going to include all immune (IM) markers and calculate the standarised mean difference (g; with heteroscedastic population variances) as the effect size of analysis comparing hibernation versus euthermia. Positive SMD values indicate higher IM values in hibernation while negative SMD indicate lower IM values in hibernation. This is a summary of the effect size calculation based on the dataset above:

Initial meta-analysis:

This initial model contains only the intercept and four random effects to account for phylogenetic variation and variation between and within studies beyond sampling variance.

## calculate var-cover matrix to control for correlated effect sizes within study and tissue
V <- vcalc(
  vi = SMDH.sv,
  cluster = Study_ID,
  subgroup = Tissue,
  grp1 = Hib_M,
  grp2 = Euthermia_M,
  w1 = Hib_N,
  w2 = Euthermia_N,
  data = df_SMD
)

# model
model_SMD <- rma.mv(
  yi = SMDH,
  V = V,
  mods = ~1,
  random = list(
    ~ 1 | scientific_name_phylo,
    ~ 1 | Species,
    ~ 1 | obsID,
    ~ 1 | Study_ID
  ),
  data = df_SMD,
  R = list(scientific_name_phylo = phylo_cor),
  method = "REML",
  control = list(optimizer = "BFGS"),
  verbose = F
)
saveRDS(
  object = model_SMD,
  file = here(
    './04_models/01_hibernation/01b_metamodel_hibernation_IM.RDS'
  )
)
